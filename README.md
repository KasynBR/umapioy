# Umamusume Atlas

A modern community-style database UI for Umamusume: Pretty Derby, built with Next.js App Router, TypeScript, Tailwind CSS, Lucide icons, and Recharts.

## Run locally
```bash
npm install
npm run dev
```
Then open http://localhost:3000.

## Sections
- Characters: profiles, aptitudes, stats, and training focus.
- Support cards: type, rarity, and effect summaries.
- Skills: category, rarity, and concise effect descriptions.
- Search and category navigation.

## Data note
This repository currently includes illustrative demo records to demonstrate the interface. Verify all gameplay statistics, skill effects, card effects, translations, and release dates against current game data before relying on them. Community references for further research: [GameTora](https://gametora.com/umamusume), [uma.guide](https://uma.guide/), [UmamusumeDB](https://umamusumedb.com/), and [TeioStep](https://teiostep.net/).

This is an unofficial fan project and is not affiliated with Cygames.
